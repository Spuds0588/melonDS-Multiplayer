offline join code ------
Local splitscreen host — one emulated console per player on the native bridge (src/frontend/tauri/melonds_bridge.h), linked over melonDS virtual Wi-Fi. Gamepads are picked up as they connect and assigned to players in order (the picker under each console reassigns one); keys 1-4 switch which console the keyboard drives; hold Shift-Right (or press Tab) to peek at that console's touch screen; the mouse is the pen on it at all times, shown or not.
